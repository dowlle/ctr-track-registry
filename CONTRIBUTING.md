# Contributing

## Adding or correcting a track

Do it through AP-Pie, not through a pull request here:

1. Open the custom tracks page on [AP-Pie](https://ap-pie.com) and sign in with
   Discord.
2. Submit a new track, a new revision of an existing track, or a correction to a
   title or credit. Include a link to the page where the track is published.
3. A maintainer reviews the submission. Nothing becomes public until it is
   approved.
4. Approved entries reach this repository in the next export pull request.

If a creator wants a title or credit changed or an entry withdrawn, use the
correction form on AP-Pie or open an issue here.

## What belongs in this repository

Names, credits, hashes, descriptors and links. **Never track files** (`.lev`,
`.vrm`, `.sca`, archives, textures, audio). CI rejects them.

## Pull requests

The data files are generated by AP-Pie's export job. A pull request that edits
them by hand will fail review. Welcome as pull requests:

- fixes to `tools/check_registry.py` and the workflow
- documentation improvements

## Running the checks locally

    python tools/check_registry.py .
    python tools/check_registry.py . --previous ../older-checkout

The second form is the freeze check: it fails if any track, block index,
shipped name or verified hash from the older checkout changed or is missing.
